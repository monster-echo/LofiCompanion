# 产品需求文档

版本：0.1  
状态：MVP 决策基线

## 1. 产品定位

一句话：进入一间会响应你学习状态的 Lofi 陪伴房间。

用户不是来“生成视频”，而是为了更容易开始学习、安静完成一轮，并看到努力如何
长期改变自己的陪伴空间。

## 2. 目标用户与核心任务

首要用户：需要独自完成作业、阅读、备考或编程的学生与年轻知识工作者。

核心任务：当我准备独自学习时，让一个熟悉的角色和空间陪我低阻力开始，在不打扰
我的前提下同步关键行为，并把每次完成沉淀为可见成就。

次要任务：和少量好友或自习小组一起坚持，知道彼此正在努力，但不暴露具体任务内容。

## 3. 产品原则

1. 陪伴先于生成：没有实时生成，免费皮肤也必须完整可用。
2. 连贯先于数量：一套皮肤的动作连续性比十套不一致的素材重要。
3. 学习先于游戏：所有成就来自有效专注，不销售等级、名次或连续天数。
4. 安静先于互动：专注中 UI 弱化，角色不频繁说话和弹窗。
5. 本地可用：离线可以开始、暂停、恢复和完成会话。
6. 隐私最小化：排行榜不共享任务正文；公开昵称与好友可见性由用户选择。

## 4. 核心循环

```text
选择陪伴皮肤
  → 选择学习活动与时长
  → 进入 Lofi 专注循环
  → 喝水/暂停/休息等事件触发短动作
  → 完成一轮并记录学习结果
  → 解锁成就和房间收藏物
  → 更新好友榜/小组共同目标
  → 返回同一个持续成长的房间
```

## 5. P0 功能范围

### 5.1 首次体验

- 游客无需注册即可浏览三套免费皮肤并开始第一轮。
- 默认活动为“写作业”，默认时长 25 分钟，可选阅读、编程、背单词和自由专注。
- 第一轮结束后再解释同步、排行榜和定制皮肤为何需要账号。
- 不在首次启动展示订阅墙。

### 5.2 陪伴皮肤

每套皮肤必须包含：

- 角色与场景设定、封面、主题令牌和版权/来源信息。
- `ready`、`focusing`、`paused`、`drinking`、`resting`、`completed` 状态。
- 至少两条可循环的专注视频、一张离线兜底图、一条独立环境音轨。
- 状态事件到动作资产的映射、优先级、冷却时间和返回状态。
- 明暗模式、减少动态效果和静态图降级策略。

免费皮肤：雨夜书房、阳光教室、深夜工作台。名称是 MVP 内容假设，可由后台调整。

### 5.3 专注会话

- 模式：倒计时；P0 快捷时长 15/25/45/60 分钟。
- 操作：开始、暂停、继续、喝水、提前结束、完成。
- 后台和强杀恢复基于时间戳及暂停区间推导，不依赖前台秒数累加。
- 同一账号最多一个活动会话；离线完成后使用幂等键同步。
- 专注 5 秒后弱化控制层；触摸或辅助技术聚焦后恢复。
- 事件视频播放失败不能影响计时，立即回退基础循环或静态图。

### 5.4 事件驱动陪伴

P0 事件表：

| 事件 | 来源 | 默认动作 | 优先级 | 是否可打断 |
|---|---|---|---:|---|
| `session.ready` | 系统 | 坐好准备 | 60 | 是 |
| `focus.started` | 计时器 | 开始学习 | 80 | 否 |
| `focus.loop` | 播放器 | 写作业/阅读循环 | 10 | 是 |
| `wellness.drink` | 用户 | 拿杯、喝水、放回 | 70 | 否 |
| `focus.paused` | 用户/系统 | 停笔等待 | 90 | 是 |
| `break.started` | 计时器 | 伸懒腰/离桌 | 80 | 否 |
| `focus.resumed` | 用户 | 回到学习姿势 | 90 | 否 |
| `focus.completed` | 计时器 | 抬头回应 | 100 | 否 |

调度器一次只播放一个动作。高优先级事件可替换等待队列中的低优先级事件；过期事件
不补播；同类健康事件有冷却时间。音频独立连续播放，避免切片导致环境声断裂。

### 5.5 完成与学习记录

- 完成页展示活动、有效分钟、今日累计、本周目标进度。
- 用户可记录一句成果，默认可跳过。
- 历史页提供按周趋势、科目分布和会话时间线。
- 提前结束保留实际时长，但是否计入榜单由服务端规则版本判定。

### 5.6 学习成就与房间成长

- 成就只由服务端根据有效会话和规则版本发放。
- 示例：第一次专注、连续七天、雨夜十小时、百轮学习。
- 成就可以解锁书签、小台灯、绿植、合影等房间收藏物。
- 收藏物是装饰和记忆，不提高计时收益或排行榜分数。
- 同一成就不会重复发放；断签不回收既有成就。

### 5.7 排行榜与自习小组

- 默认提供好友周榜和小组周榜，不做 P0 全国总榜。
- 只计算完成且通过服务端校验的有效专注；每日最多计入 180 分钟。
- 中途退出不计榜单分，但历史仍保存实际有效分钟。
- 排行榜展示昵称、头像、有效分钟和名次，不展示任务正文。
- 用户可关闭公开昵称或退出榜单，不影响基础学习和成就。
- 小组显示共同目标、个人贡献和正在专注的人数，不提供公开陌生人聊天。

### 5.8 账号、通知与设置

- 复用 MobileStarter 的邮箱、手机号、Apple/Google/微信登录适配。
- 通知仅用于用户设定的开始提醒、休息结束和小组目标结果。
- 设置包含默认时长、声音、自动播放、网络偏好、减少动态、语言、隐私和数据管理。
- 支持数据导出、账号删除、恢复购买和订阅管理。

## 6. P1 功能

- 模板化定制皮肤：先生成静态参考图，用户确认后生成状态视频。
- 官方付费皮肤与季节皮肤包。
- 桌面/锁屏小组件、Live Activity、Android/HarmonyOS 计时通知。
- 好友邀请、私密自习小组、组内挑战和房间合影。
- 更多事件：白天/夜间、天气、翻页、键盘、休息活动。
- 皮肤工坊的任务中心、失败重试、审核和资产版本管理。

## 7. 明确不做

- 不承诺替换整个手机系统主题。
- 不监听摄像头或麦克风推断用户是否真的学习。
- 不做无限 AI 聊天、陌生人社交广场或公开聊天室。
- 不用实时视频生成阻塞专注开始。
- 不销售学习时长、排行榜名次、连续天数或核心成就。
- 不把逆向供应商接口、共享 Cookie 或 sessionid 放进生产链路。

## 8. 成功指标

北极星指标：每周完成至少三轮有效专注的活跃用户数。

首轮验证指标：

- 新用户 90 秒内开始第一轮的比例。
- 第一轮完成率和第 2 天/第 7 天再次专注率。
- 事件按钮使用率、事件播放成功率和动作后返回专注率。
- 皮肤切换率、免费皮肤偏好分布和房间收藏物查看率。
- 好友榜自愿加入率、小组目标完成率。
- 官方皮肤详情到购买转化率、定制预览到付费转化率。
- 视频生成成功率、P50/P95 耗时、单套真实成本和退款正确率。
