# 收费与权益机制

版本：0.1  
说明：本文件中的价格是首轮验证假设，不是已确认商业政策。上线价格必须基于供应商合同、
商店抽成、税费、生成成功率和真实用户测试重新核定，并通过远程配置发布。

## 1. 收费原则

- 基础专注、学习记录、基础成就、数据导出、账号删除和无障碍功能永久免费。
- 用户为“更丰富的陪伴内容”和“真实产生供应商成本的个性化生成”付费。
- 不出售学习分钟、连续天数、排行榜名次、有效成就或提高榜单分数的道具。
- 价格、周期、自动续费、额度有效期和退款条件在确认购买前清楚显示。
- 生成失败自动释放冻结额度；重复回调和重试不能重复发放权益。

## 2. 产品矩阵

### Free

- 三套完整免费皮肤。
- 计时、喝水/暂停/休息/完成事件。
- 完整个人学习历史和基础周统计。
- 基础成就与免费房间收藏物。
- 好友榜、小组榜和自愿公开隐私设置。
- 已下载皮肤离线使用。

### Companion Plus 订阅

- 所有订阅期内的官方高级皮肤和季节皮肤。
- 高级房间布置槽位、环境音和更多事件动作。
- 高级学习洞察和跨设备皮肤/房间同步。
- 每月发放少量定制额度；额度数量由真实成本后确定。
- 订阅到期后：已购买/自生成皮肤保留；订阅目录皮肤停止新增使用，当前皮肤安全回退。

首轮价格假设：`¥18/月`、`¥168/年`。必须 A/B 验证，不写死在客户端。

### 官方皮肤单买

- 用户可永久解锁一套官方皮肤，不要求订阅。
- 建议价格带：`¥6–¥18/套`，取决于状态视频数量和音频内容。
- 单买权益绑定账号，支持商店恢复购买。

### AI 定制生成

- 先免费或低成本生成静态预览；用户确认后才报价生成视频状态。
- 标准包：角色参考图 + 4 个核心事件状态。
- 完整包：角色参考图 + 8 个事件状态 + 环境音/房间配置。
- 首轮对外价格假设：标准 `¥39`、完整 `¥69`；仅在真实单位经济成立后开放。
- 生产系统内部使用 credits 结算供应商成本，但消费者购买页优先展示人民币结果和包含内容，
  不用模糊兑换关系诱导消费。

## 3. 生成额度机制

额度只用于 AI 定制，不用于官方皮肤、专注、成就或排行。

```text
购买/订阅发放额度
  → available
创建任务并确认报价
  → available 减少，reserved 增加
生成成功并入库
  → reserved capture
确定失败/可取消
  → reserved release 回 available
已扣费后人工纠错
  → refund ledger
```

额度分桶记录来源和有效期：购买额度默认长期有效；订阅额度按商店政策和明确页面规则生效。
消费顺序固定为先使用最近到期额度，再使用长期额度。任何余额变化必须有不可变账本记录。

## 4. 权益键

建议稳定 entitlement keys：

- `skin.official.{skinId}`：单套永久皮肤。
- `catalog.premium.active`：订阅目录访问权。
- `room.advanced_slots`：高级布置槽位。
- `insights.advanced`：高级学习洞察。
- `generation.custom.enabled`：允许进入定制流程。

生成额度不是布尔 entitlement，单独进入 credit ledger。客户端隐藏按钮不能替代服务端权限检查。

## 5. 支付与订单

渠道：

- iOS：StoreKit 与 App Store Server API。
- Google Play：Play Billing 与服务端购买校验。
- HarmonyOS：中国区按 HMS IAP 能力和发布渠道确认。
- 微信/支付宝：只在渠道政策允许的客户端或 Web 场景启用。

订单流程：

```text
读取服务端商品目录
  → 商店返回本地化价格
  → 创建幂等订单
  → 客户端完成商店购买
  → 服务端验证交易
  → 订单成功与权益发放原子提交
  → Webhook 更新续订、退款和撤销
```

必须支持购买中断恢复、恢复购买、退款/撤销、重复 Webhook 去重和人工对账。客户端收据或成功
回调不是最终信任来源。

## 6. 单位经济门禁

定制生成开放付费前必须测得：

- 每个状态视频供应商价格和平均重试成本。
- 静态预览到最终成功的端到端成功率。
- P50/P95 生成耗时与人工审核成本。
- 对象存储、转码、CDN 和长期保存成本。
- 商店抽成、税费、退款率和客服成本。

标准包贡献毛利计算：

```text
净收入
- 供应商生成成本
- 平均失败重试成本
- 转码/存储/CDN
- 支付/商店费用
- 退款与人工审核准备金
= 单套贡献毛利
```

未达到目标毛利时，优先减少生成状态、提高缓存/复用和调整价格，不允许用不透明失败规则转嫁成本。

## 7. 远程配置

服务端动态配置：

- 计划、价格展示、试用、促销窗口和地区币种。
- 官方皮肤所属商品、订阅目录和下架策略。
- 每种生成模板的报价版本、额度成本和供应商能力。
- Free/Plus 权益，不在客户端写死数量。
- 生成总预算、用户日限额、并发数和紧急关闭开关。

## 8. 收费验收

- 未购买用户无法通过直接 API 获得付费皮肤 manifest。
- 同一商店回调重放十次只发放一次权益。
- 生成失败后 reserved 清零、available 恢复，账本可对账。
- 订阅到期、退款和撤销按规则更新权益，不删除用户自己的学习数据。
- 所有价格来自服务端/商店，不使用客户端硬编码假价格。
- 审核账号可以完成游客体验、测试购买和恢复购买。
